# 元搜索与搜索器自进化

ArchNova 将搜索器本身建模为可审查对象。`meta_search.py` 提供动态适应度草案、算子目录元进化建议、Plan-Execute-Summarize 闭环、复杂度 niche、硬件多目标 Pareto、组件缺口检测、组件生长提案和静态/符号依赖检查。

适应度控制器只能根据已记录的搜索轨迹调整权重，并标记 `requires_review`；它不能把启发式分数升级为真实性能。算子元进化只生成弃用、修复或增加采样的建议，必须由验证器和人工审查确认。复杂度分区确保候选不会集中在单一成本带，硬件 Pareto 同时保留质量、延迟、能耗、显存和面积的非支配解。

零件库生长从失败候选中检测缺失能力，再生成带接口契约、计算契约、来源和验证门的设计草案。缺口检测不是新算子已存在的证明；组件必须经过静态契约、符号/数值一致性、消融和可复现实现审查后才能进入可用库。
