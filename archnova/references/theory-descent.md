# 理论下潜（Theory Descent）

架构改进的上限由**函数类**决定。不知道当前算子属于哪个族、下一族是什么，所谓「改进」只能是在超参空间里游走。本文件给出四层下潜的产出要求、已知数学重构的锚点、以及区分真理论与伪理论的操作规则。

---

## 1. 四层下潜

| 层 | 要回答 | 必须产出 | 不合格的样子 |
|---|---|---|---|
| L1 函数类实例化 | 这个架构整体在逼近什么数学对象？ | 写出映射的类型签名（如 `G: U → V`，U、V 是哪个函数空间） | 「它在做特征提取」 |
| L2 表达力与速率 | 它能表示什么、表示得多好、需要多少参数/样本？ | 定理名 + **完整重述假设** + 结论的速率形式（如 `O(m^{-s/d})`） | 只写「有万能逼近性质」 |
| L3 算子重构 | 用哪个算子族重写它？ | 算子族名 + 核/谱/半群的显式形式 + 离散化方式 | 「可以看作一个积分算子」而不写核 |
| L4 下一层算子 | 沿这个族往上，下一层是什么？需要什么条件才成立？ | 候选算子 + 适用条件 + 破缺后的退化行为 | 堆砌术语名词 |

## 2. 一个判据：架构应当实例化数据生成过程的解算子

若数据由某个过程生成，最优的归纳偏置是**该过程解算子的结构**：

| 数据生成过程 | 解算子的结构 | 对应架构 |
|---|---|---|
| 平移不变滤波 | 卷积（Toeplitz/循环矩阵） | CNN |
| 线性 ODE / 马尔可夫过程 | 算子半群 `e^{tA}` | SSM、RNN |
| 带核的积分方程 | 核积分算子 | 注意力、核方法 |
| 常系数 PDE（周期边界） | Fourier 乘子 | 谱方法、FNO |
| 一般非线性算子 | 分支×主干的双函数空间编码 | DeepONet |
| 多尺度介质 | 均匀化算子（双尺度极限） | 多尺度/分层算子 |

**用法**：拿到架构后先问「它假设了哪种数据生成结构」。若数据实际结构不匹配，这就是一个**结构性缺陷**——比任何超参调整都更值得改。

## 3. 已知数学重构锚点（编号已核验）

下表是常用的「把架构翻译成算子」的落点。它们既是 L3 的参照，也是检索上游的起点。**引用时仍需在发布前用 `check_anatomy.py --verify-refs` 复核元数据。**

| 架构 | 数学重构 | 锚点 |
|---|---|---|
| 线性注意力 | 核特征映射 + 结合律：`Σ_j (φ(q)·φ(k_j)) v_j = φ(q)·Σ_j φ(k_j) v_jᵀ`，故可线性扫描 | Transformers are RNNs, arXiv:2006.16236 |
| softmax 注意力 | 退化核积分算子；可选用 Fourier 型或 Galerkin 型投影 | Choose a Transformer: Fourier or Galerkin, arXiv:2105.14995 |
| 注意力（核视角） | 与核平滑/Nadaraya-Watson 估计同构 | Transformer Dissection, arXiv:1908.11775 |
| Transformer 表达力 | 序列到序列函数的万能逼近（需重述其假设与序列长度条件） | Are Transformers universal approximators, arXiv:1912.10077 |
| 神经算子 | 函数空间之间的映射，离散无关性（resolution invariance） | Neural Operator, arXiv:2108.08481 |
| FNO | 截断 Fourier 乘子 = 有限秩的平移不变卷积算子 | FNO, arXiv:2010.08895 |
| DeepONet | `G(u)(y) ≈ Σ_k b_k(u) t_k(y)`，分支/主干分别编码输入函数与查询坐标 | DeepONet, arXiv:1910.03193 |
| Mamba | 输入依赖的线性 ODE 离散化（ZOH），选择性来自时变参数 | Mamba, arXiv:2312.00752 |
| MLA | KV 的低秩联合压缩（隐空间缓存），把 cache 从 `2·L·N·D` 压到 `L·N·c` | DeepSeek-V2, arXiv:2405.04434 |
| MoE 路由 | 条件计算：`y = Σ_{i∈TopK} g_i(x)·E_i(x)`，负载均衡是约束优化 | DeepSeek-V3, arXiv:2412.19437 |

## 4. 伪理论的五种形态（写报告时逐条自查）

1. **万能逼近当解释**。万能逼近只说明「足够大就能逼近」，不说明**需要多大**、**需要多少样本**、**优化能否找到**。把它当成「为什么有效」是偷换。合格写法：给出速率或显式说明「本文只有定性结论」。
2. **定理假设被悄悄放宽**。引用定理时必须逐条重述假设（紧性、Lipschitz、测度绝对连续、序列长度上界……），并标明本架构是否满足。有一条不满足，结论就不成立。
3. **类比无映射**。「注意力像物理中的相互作用」——写出 φ 与不变式，否则删掉（见 `improvement-ops.md` §7）。
4. **只给名字不给式子**。「这是非局部算子」——非局部算子的定义式、核的奇异性阶数、可积性条件在哪？
5. **拿实现当理论**。「用了 FlashAttention 所以等价于 IO 感知算法」——那是计算重排，不改变算子。

## 5. 适定性与速率：必须计算的量

对每个理论级提案，至少给出下列之一的具体形式（不能只有定性描述）：

- **逼近速率**：误差随参数 m、维度 d、光滑度 s 的阶，例如谱方法类 `O(m^{-s/d})`。注意 `s/d` 说明高维下光滑性红利被维数吃掉——这正是「为什么需要架构先验」的定量理由。
- **样本复杂度**：达到误差 ε 所需样本数随 d 的增长。
- **Lipschitz/稳定性常数**：随层数 L 的增长方式（例如 `∏‖W_l‖` 型界），这决定了深度的可行性。
- **离散化误差**：网格尺寸 h 与误差的关系，以及是否与分辨率无关。
- **条件数**：需解线性系统时的 κ 随 N 的变化。

写不出这些时，明确写「本文档只给到定性层级，定量速率属 `M`」，而不是含糊其辞。

## 6. L4：往上一层是什么（候选算子族与其成立条件）

| 候选族 | 形式 | 成立条件 | 破缺时的退化 |
|---|---|---|---|
| 非局部算子 | `(Ku)(x) = ∫ k(x,y) u(y) dy`，k 可奇异 | 核的可积性与有界性 | 核过尖 → 退化为局部；过平 → 退化为均值 |
| 分数阶算子 | `(-Δ)^{s/2}`，s∈(0,2) | 需在合适 Sobolev 尺度上定义 | s→2 退化为 Laplacian；s→0 退化为恒等 |
| 非马尔可夫记忆核 | `h_t = ∫_0^t K(t-s) f(h_s) ds` | 记忆核可积、卷积可实现 | 核衰减过快 → 退化为 SSM；过慢 → 状态不可压缩 |
| 多尺度/均匀化算子 | 双尺度极限 `u_ε ⇀ u_0` | 尺度分离、周期性或遍历性 | 无尺度分离 → 均匀化不成立 |
| 测度值算子 | 输出为概率测度，用 Wasserstein 度量 | 连续性/紧性 | 目标为确定性场时属过度设计 |
| 变域算子 | 定义域本身可变（几何参数化） | 域参数化的紧性、网格一致性 | 域变化剧烈 → 需重网格化 |
| 随机算子（SDE/Fokker-Planck） | 半群作用于分布 | 漂移/扩散系数正则性 | 确定性数据下引入不必要方差 |

**选择规则**：只有当数据生成过程确实具备该结构（例如真有多尺度分离、真有长记忆）时才升级算子族；否则是过度设计。判断依据要写出（如数据的谱衰减速率、自相关函数衰减）。

## 7. 前沿理论方向的检索方式

理论不是靠记名字，是靠找**当前仍在推进的表述**。检索策略：

- 搜算子学习的**逼近速率与泛化界**：`approximation rate neural operator`、`generalization bound operator learning`；
- 搜**对称性与等变**的形式化：`equivariant operator learning`、`symmetry constrained neural operator`；
- 搜**谱偏置**的定量刻画：`spectral bias neural network`、`frequency principle`；
- 搜**测试时计算**的理论：`test-time compute scaling law`、`inference-time scaling`；
- 搜**路由/稀疏**的理论：`mixture of experts approximation theory`、`routing collapse analysis`。

每篇找到的理论工作，必须能回答：「它的结论对我的架构施加了什么约束？」回答不了就只是背景阅读，不写进报告的理论节。
