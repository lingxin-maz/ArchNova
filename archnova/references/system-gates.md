# 系统级合法性门

安全上下文连续性（ECI）要求每个外部效果都能通过见证链连接到来源、主体、任务、字段级溯源、根授权、组件契约和当前策略。单个组件通过安全审查不能替代组合后的见证链；序列化丢失标签、别名重写或策略绑定断裂会阻塞候选。

物理基底是架构合法性的一部分。Chiplet、2.5D 封装、存内计算或专用加速器必须提供分区、互连带宽、功耗和吞吐收据。缺少目标基底合同只能标记 unresolved。

归纳偏置兼容性检查任务所需偏置是否由当前组件覆盖。缺失时需要任务专用非线性或新组件提案，不能继续假设通用零件库足够。

不可见层审计会检查同步边界、权限连续性、状态生命周期、重放语义和其他被隐含假设的运行时条件。未显式绑定到组件契约或依赖清单的条件会被报告为缺失层。

`system_gates.py` 的 `system_admission` 对这些门统一裁决：任何 blocked 阻止晋升，unresolved 只能保留为设计候选。
