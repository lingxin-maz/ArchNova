# 报告模板（Report Template）

v2 的实际报告由 `scripts/render_report.py` 从 anatomy.json 生成并由 checker 精确核对。以下模板作为研究内容清单，不再另行手写一份事实来源。

报告是本技能的最终产物。模板固定，是为了让不同论文的解剖结果**可横向比较**，也让检查器能做确定性校验。

**全程使用三种标注**，任何一句话都必须能归入其中一种：

- 【事实】论文原文，附位置（`p7 §3.2`、`eq(4)`、`Tab.2`）
- 【推断】你的推导或判断，附推导过程
- 【缺失】检索后仍未知，附检索记录

## 写作纪律

1. **先表后文**。表格填不满的地方，暴露的是证据缺口，不是文笔问题。
2. **不写没有落点的形容词**。「高效」「强大」「优雅」必须替换成具体的槽位与量。
3. **每个提案必须能失败**。写不出 kill_criterion 的想法放进 §6.4。
4. **引用只出现在该出现的地方**。上游论文只用于补缺口，不用于装点背景。
5. **长度服从信息密度**。一份合格的深度解剖通常是 2500–5000 字 + 表格；短于 1500 字基本意味着没做下游与理论。
